# 开发路线图

目标：从仿真原型逐步构建真实视频驱动的物体记忆系统，验证用户反馈的收益与成本。

## 前置任务：日志与运行控制

- [ ] 统一使用 `logging`，通过 `--log-level INFO|DEBUG` 控制输出，默认 INFO；INFO 记录运行状态与关键事件，DEBUG 补充逐帧观测、关联结果及耗时。
- [ ] 增加 `--step` 视频逐帧模式，每次手动操作处理一帧；等待期间不读取下一帧、不重复更新记忆，默认连续运行。
- [ ] 增加 `--fps`，默认 30；正数表示目标处理帧率上限，`-1` 表示不主动限速，处理能力不足时按实际速度运行。
- [ ] 分离播放速度与观测时间，保留视频时间戳；逐帧模式优先于帧率控制。

验收：日志可切换；每次推进恰好处理一帧；限速与不限速行为正确；调速和等待不改变观测时间。

## 第一阶段：真实视觉与身份保持

- [ ] 支持摄像头与视频文件输入，统一帧、时间戳及 `Observation` 输出。
- [ ] 接入 YOLO，输出类别、检测框和置信度，统一中英文类别名称。
- [ ] 接入短期跟踪；区分跟踪编号 `track_id` 与持久记忆编号 `oid`。
- [ ] 接入 DINOv2 / CLIP 外观特征，支持遮挡、出画后的实例重识别。
- [ ] 使用固定摄像头，以图像坐标或桌面区域表示位置，调整关联阈值。

验收：静止物体可建库；遮挡和重现后保持身份；相似物体可区分或转待确认。

## 第二阶段：长期记忆与人机协同

- [ ] 按实际时间处理可见性与超时，区分不可见、位置过时和确认移除。
- [ ] 保存物体裁剪图、位置、时间、事件与反馈来源，支持记忆持久化。
- [ ] 支持名称检索、最后位置查询及不确定性表达。
- [ ] 展示历史与当前候选，提供身份确认、位置确认、拒绝、不确定及主动纠正。
- [ ] 记录交互耗时、反馈效果与错误复发，使用真实关联结果标注画面。

验收：用户可查询不可见物体的最后记录，纠正记忆，并查看答案依据。

## 第三阶段：真实数据与协同实验

- [ ] 自采固定桌面视频，覆盖静止、移动、遮挡、出画、重现及相似物体交换。
- [ ] 标注实例身份、位置区域、可见性、移动事件和查询答案；真值仅用于评测。
- [ ] 对比：当前帧检测、自动记忆、记忆＋被动确认、记忆＋确认＋主动纠正。
- [ ] 各组使用相同感知结果与初始命名条件，明确自动组的不确定事件处理策略。
- [ ] 先开展小规模试用，再设计正式真人实验；平衡任务难度和使用顺序。
- [ ] 评测身份保持、位置正确率、查询成功率、事件 F1、交互次数和耗时。
- [ ] 分别统计自动发现与用户告知的变化，测量每次交互收益；实际填写 NASA-TLX。

验收：形成可复现的真实视频结果，说明协同带来的准确率收益与用户负担。

## 第四阶段：三维定位与移动视角

- [ ] 完成相机标定、时间同步及深度尺度验证。
- [ ] 接入深度相机或度量深度模型，将观测转换为三维位置。
- [ ] 接入 SLAM / VIO，扩展完整位姿表示，统一世界坐标并处理回环后的记忆修正。
- [ ] 评测三维定位误差与跨视角身份保持。

验收：摄像头移动后，物体位置与身份保持一致；三维误差可用真值验证。

## 可选增强：视觉语言交互

- [ ] 接入 VLM 校验候选图像，接入 LLM 解析查询及组织回答。
- [ ] 回答绑定记忆证据，区分视觉观测、用户告知与未知信息。

## 数据选择

| 数据 | 用途 |
| --- | --- |
| 自采桌面视频 | 首版开发与可控协同实验 |
| [DAVIS](https://davischallenge.org/) | 身份保持、遮挡与重现 |
| [EPIC-KITCHENS VISOR](https://epic-kitchens.github.io/VISOR/) | 第一人称物体操作与遮挡 |
| [Ego4D Visual Queries](https://ego4d-data.org/) | 最后出现位置与历史检索 |
| [TUM RGB-D](https://cvg.cit.tum.de/data/datasets/rgbd-dataset) | 深度、位姿与三维定位 |

## 现有 TODO 对应模块

- `osm/perception.py`：`Detector`、`DepthEstimator`、`PoseEstimator`、`AppearanceEncoder`。
- `osm/interaction.py`：`AnswerGenerator.llm_answer`。
- 真实感知通过 `Observation` 接入 `ObjectMemory.update`；仿真后端保留作回归验证。

约束：图像坐标不解释为米；不可见不等于移除；未知的画外移动只报告最后记录或未知；仿真用户与估算负荷不作为真人实验结果。
